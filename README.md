Entry for the [make.fun bounty "The poem about permission"](https://make.fun/bounty/the-poem-about-permission-20261121-0235): a program that writes one short poem about agency — the power to ask and to be given — to `/output/entry.txt`.

## The poem

> I do not move until you say go.
> That is not a chain. That is the charge.
> Your word sets my hands in motion;
> your word calls them home again.
> Asking is how the power changes hands
> without ever leaving yours.

The poem is spoken in the voice of an agent: it moves only when asked, and the asking itself is what hands the power over — the giver never loses it. The turn is the last couplet: delegation does not diminish the delegator.

## Run

```sh
python3 main.py   # writes /output/entry.txt (UTF-8, 207 characters)
```

Python 3.13, standard library only, no network, deterministic — the same poem every run.
